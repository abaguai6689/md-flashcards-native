# 计算机网络速记

## TCP 三次握手

客户端发送 **SYN**，服务端回复 **SYN+ACK**，客户端再回 **ACK**。

### 为什么不是两次

防止历史连接请求造成资源浪费，同时确认双方收发能力。

## HTTP 与 HTTPS 区别

HTTPS 在 HTTP 与 TCP 之间加了 TLS 层，提供加密、身份认证与完整性校验。

## 进程与线程

进程是资源分配的基本单位，线程是 CPU 调度的基本单位；同一进程内的线程共享地址空间。

## 常见状态码

| 状态码 | 含义 |
| --- | --- |
| 200 | 成功 |
| 301 | 永久重定向 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |
